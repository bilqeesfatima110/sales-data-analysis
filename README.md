### Sales Data Analysis
## Overview
This project analyzes a retail Superstore sales dataset using Python to understand sales performance across time, products, customers, and regions.

## Dataset
9,800 records and 18 columns <br>
Date range: January 2015–December 2018 <br>
4,922 unique orders and 793 unique customers <br>

## Tools
Python, <br>
Pandas, <br>
NumPy, <br>
Matplotlib, <br>
Seaborn, and Jupyter Notebook.

## Methodology
The dataset was checked for missing values, duplicates, and data types. Date columns were converted to date format. Sales were analyzed by year, month, category, product, customer, and region. Charts and statistical methods were used to present patterns.

## Key Findings
Total sales: **$2,261,536.78** <br>
Highest-sales year: **2018** <br>
Highest-selling category: **Technology** <br>
Highest-selling sub-category: **Phones** <br>
Top product by sales: **Canon imageCLASS 2200 Advanced Copier** <br>
Top customer by sales: **Sean Miller** <br>
Highest-sales region: **West**

## Conclusion
The project uses data analysis and visualizations to identify sales trends and the products, customers, and regions contributing most to retail sales.
